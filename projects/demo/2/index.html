The cost of finishing

Edited 4 min ago · 1,204 words #craft #writing

Finishing is a different skill from starting. Starting wants momentum; finishing wants someone to sit with the thing until it stops changing.

“A note is a promise to your future self.”

Sennett calls this the rhythm of the workshop: the hand learns what the head forgets. The same argument, applied to money, is in [[Pricing decision, March]].

Most of my notes are overdue. The archive only pays out if the promise is easy to keep.

01 / Capabilities

A notebook with an index.

Six things the app does without asking a server for permission.

01

Local search index

SQLite FTS5 lives beside your notes. Queries run on the CPU in front of you, in about 40 ms for 4,000 notes.

sqlite · fts5
02

Links that resolve

Type [[ and pick a title. Backlinks update in the open note while you keep typing, with no save button.

wiki links
03

Quotes keep their page

A clipped paragraph stores its URL, page number and capture time. The source travels with the idea.

clipper
04

Plain files, plainly

Every note is a .md file in a folder you chose. Open it in VS Code or Obsidian while Cairn runs.

markdown
05

Sync is optional

Point the folder at iCloud, Dropbox or a git remote. Turn sync off and search, links and history keep working.

icloud · git
06

Shortcuts and a local API

Capture from the menu bar, iOS Shortcuts, a URL scheme or localhost:7777. All offline.

url scheme · http

03 / Import

Bring the last ten years with you.

Import reads the export folders other apps leave behind and writes plain Markdown. Attachments come along. Internal links are rebuilt. Nothing is uploaded.

  • Evernote
  • Notion
  • Obsidian
  • Bear
  • Apple Notes
  • a folder of .md

Tested on exports up to 40,000 notes. A dry run is the default.

zsh · cairn
$ cairn import ~/Desktop/notes-export.zip --from evernote
dry run · nothing written yet

scanning   archive          4,182 notes      ✓
resolving  internal links   11,208 edges      ✓
copying    attachments      326 files       ✓
rewriting  timestamps       4,182 ok        ✓

done in 38s → ~/Cairn (11.4 MB)
$

04 / Install

Install it. Point it at a folder.

No account, no onboarding wizard. The archive opens in under a second, and the folder stays yours.

brew install cairn

macOS 13+ · 14 MB · or download the .dmg · iOS build requires TestFlight
