    02 · Method

    How a thought gets kept.

    Nothing to file.
    Nothing to tidy.

    1. 01

      Catch it where it happens.

      Share sheet, menu bar, watch, voice memo. Every capture lands in the same inbox, as text, with the place it came from.

    2. 02

      Let the links form.

      Cairn suggests links from names, dates and phrases you repeat. Accept the ones that help. Ignore the rest.

    3. 03

      Find it by the idea.

      Search by meaning and by source. A result opens at the paragraph, so you can see what you were thinking around it.

    Why this exists

    A note you cannot find is a note you never wrote.

    Most tools help you write. Fewer help you remember. Cairn is built for the second job: the folder you open when a half-formed thought needs its other half.

    The Cairn method, 2026

    03 · Files

    Your notes are files.
    They outlive the app.

    Cairn writes Markdown into a folder you choose. Sync is that folder on another disk. There is no import step, because there was never an export step.

    Open format
    Every note is a .md file. Links are brackets; tags are hashes.
    Offline by default
    The archive opens with the network off. Forever.
    Yours to leave
    Point Cairn at an empty folder and drag yours out. No queue, no migration wizard.
