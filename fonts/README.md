# Font kit

All families are SIL Open Font License, latin subset, weights 400 and 700. Each folder has a ready `font.css` with relative `url()` paths.

- Inter — `inter/font.css`
- Space Grotesk — `space-grotesk/font.css`
- Archivo — `archivo/font.css`
- Manrope — `manrope/font.css`
- DM Sans — `dm-sans/font.css`
- Sora — `sora/font.css`
- Work Sans — `work-sans/font.css`
- Fraunces — `fraunces/font.css`
- Instrument Serif — `instrument-serif/font.css`
- Playfair Display — `playfair-display/font.css`
- Crimson Pro — `crimson-pro/font.css`
- Libre Baskerville — `libre-baskerville/font.css`
- IBM Plex Sans — `ibm-plex-sans/font.css`
- IBM Plex Mono — `ibm-plex-mono/font.css`
- JetBrains Mono — `jetbrains-mono/font.css`
- Bricolage Grotesque — `bricolage-grotesque/font.css`

Copy the folders you use into `assets/fonts/` and either include `font.css` or copy its `@font-face` rules. If you need a family that is not here, download it into `assets/fonts/` yourself.
